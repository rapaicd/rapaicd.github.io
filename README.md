# Danilo Apps website

Public pages for Danilo Apps, served by GitHub Pages at https://rapaicd.github.io/.

- `index.html`: home page (Google sign-in branding needs one)
- `sedi-i-vozi/privacy.html`: privacy policy of the Sedi I Vozi app (Serbian + English)
- `sedi-i-vozi/delete-account.html`: how to delete an account, with or without the app (required by Google Play)

The pages are self-contained (no external fonts or scripts), so visitors send no data to third parties. Each app gets its own folder.

Published URLs are used by the apps, Google Play and Google sign-in: never rename or move a page.
